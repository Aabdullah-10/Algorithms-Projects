# Sorting Benchmark Lab

## Requirements
- Python 3
- Matplotlib

## Run
Install Matplotlib:

```bash
pip install matplotlib
```

Run the project:

```bash
python sorting_benchmark.py
```

The program checks the sorting algorithms, measures execution time, saves the results in `benchmark_results/results.csv`, and creates charts for sorted, reversed, and random data.

Unit tests are included in `sorting_benchmark.py` and run automatically.
